# Contributing

## Contribution Philosophy

Contributions should make the repository clearer, deeper, more correct, or easier to use offline.
Prefer practical explanations, runnable examples, and honest tradeoffs over buzzwords.

## Standards

- Keep numeric ordering for learning files.
- End every Markdown file with the navigation block.
- Avoid fake citations and unsupported claims.
- Do not add secrets, private data, or API-key-only examples.
- Run `python tools/check_links.py` before opening a pull request.
- Run relevant Python examples when changing source code.

## Suggested Pull Request Checklist

- The change teaches a concept properly.
- Links are valid.
- Diagrams render as Mermaid.
- Code examples run without external services unless clearly documented.
- New behavior has tests or a manual verification note.
