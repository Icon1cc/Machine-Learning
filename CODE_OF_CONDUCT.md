# Code of Conduct

## Expected Behavior

Be respectful, precise, and constructive. This repository is for learning difficult technical topics,
so explanations should welcome beginners while preserving rigor.

## Unacceptable Behavior

Harassment, personal attacks, gatekeeping, discriminatory language, and intentionally misleading
technical claims are not acceptable.

## Enforcement

Maintainers may edit, reject, or remove contributions that reduce safety, clarity, or trust. Technical
disagreement is welcome when it is specific and evidence-based.
